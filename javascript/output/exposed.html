1. Console Output 

console.log("Hello World!");

Output appears in the browser developer console, rather than directly on the webpage.

2. Text Output Using innerText 

document.getElementById("element-id-1").innerText  = 
    "Text changed using innerText";

Original text

3. HTML Output Using innerHTML 

document.getElementById("element-id-2").innerHTML  = 
    "Text containing <strong>HTML markup</strong>";

Original text

4. Browser Dialog Output 

alert("Hello World!");

The alert() function displays a browser dialog. It is triggered by user interaction in this example.

5. External JavaScript File 

<script src = "./Output.js"></script>

Inside script.js: 

console.log("[console.log] Output displayed in the browser console");

// SECTION 2: HTML TEXT OUTPUT
document.getElementById("element-id-1").innerText  =  "[element-id-1] Text changed using innerText";

// SECTION 3: HTML ELEMENT OUTPUT
document.getElementById("element-id-2").innerHTML  =  "[element-id-2] Text containing HTML markup";

// SECTION 4: ALERT OUTPUT
alert("[alert] Output displayed in a browser dialog");

// SECTION 5: DOCUMENT OUTPUT
// Avoid calling document.write() after the page has loaded.
// It can replace the current document.

6. Document Output Using document.write() 

document.write("Hello World!");

document.write() can write into the document while it is being parsed. Calling it after the page has loaded may replace the entire document, so it is generally avoided in modern webpage development.
