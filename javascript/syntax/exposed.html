1. Variables

Variables store values or references used by a program. let allows reassignment, while const prevents reassignment of the variable binding. However, const does not make an object immutable. var is an older declaration keyword with different scoping rules.

Expand Syntax 
// let: can be reassigned.
let number  =  64;
number  =  128;

// const: cannot be reassigned.
const pi  =  3.14159;

// Object properties can still be modified.
const settings  =  { volume: 50 };
settings.volume  =  75;

// var: older declaration syntax.
var oldVariable  =  "Declared using var";

2. Data Types

JavaScript has seven primitive types: Number, String, Boolean, Undefined, Null, BigInt and Symbol. Objects are non-primitive values, and arrays are a specialised kind of object.

Expand Syntax 
let integer  =  256;
let decimal  =  3.14;
let string  =  "This is a string";
let boolean  =  true;
let unassigned;
let myNull  =  null;
let bigInt  =  9007199254740993n;
let symbol  =  Symbol("uniqueKey");

let object  =  {
    storedString: "Stored String",
    storedBoolean: true,
    storedNumber: 128
};

let array  =  [10, 20, 30];

typeof null returns "object" because of a historical JavaScript quirk. Array.isArray() checks whether a value is an array.

Expand Syntax 
console.log(typeof integer);       // "number"
console.log(typeof string);        // "string"
console.log(typeof boolean);       // "boolean"
console.log(typeof unassigned);    // "undefined"
console.log(typeof myNull);        // "object"
console.log(typeof bigInt);        // "bigint"
console.log(typeof symbol);        // "symbol"
console.log(typeof object);        // "object"
console.log(typeof array);         // "object"

console.log(Array.isArray(array)); // true

3. Statements and Expressions

A statement is an instruction executed by JavaScript. An expression produces a value. In the final line, firstNumber + secondNumber is an expression that evaluates to 30, and the complete line is a variable declaration statement.

Expand Syntax 
let firstNumber  =  10;
let secondNumber  =  20;

let sum  =  firstNumber + secondNumber;

4. Operators

Arithmetic operators perform calculations. Comparison operators compare values, while logical operators combine or invert Boolean conditions.

Loose equality ( = = ) may convert types before comparing. Strict equality ( = = = ) compares without that type conversion. Strict equality is generally preferable when type conversion is not intended.

Expand Syntax 
let a  =  10;
let b  =  3;

// Arithmetic
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);

// Comparison
console.log(5  =  =  =  5);
console.log(5 ! =  =  3);
console.log(a > b);
console.log(a < b);

// Logical
console.log(true && false);
console.log(true || false);
console.log(!true);

// Loose and strict equality
console.log(5  =  =  "5");  // true
console.log(5  =  =  =  "5"); // false

5. Case Sensitivity

JavaScript is case-sensitive. myVariable and MyVariable are two different identifiers.

Expand Syntax 
let myVariable  =  "Lowercase m";
let MyVariable  =  "Uppercase M";

console.log(myVariable);
console.log(MyVariable);

6. Comments

Comments explain code to people reading it. JavaScript does not execute comments as program instructions.

Expand Syntax 
// Single-line comment

/*
    Multiline comment
    spanning several lines
*/

7. Strings and Template Literals

Strings represent text. Template literals use backticks and ${} to insert values or expressions into a string.

Expand Syntax 
let name  =  "JavaScript";
let version  =  2026;

let message  =  `Learning ${name} in ${version}`;

console.log(message);

8. Type Conversion

Number() converts a value into a number where possible. The string "123" becomes the number 123. Invalid numeric text such as "hello" produces NaN, meaning Not-a-Number.

Expand Syntax 
let numericText  =  "123";
let convertedNumber  =  Number(numericText);

console.log(typeof numericText);     // "string"
console.log(typeof convertedNumber); // "number"

console.log(Number("hello")); // NaN
