1. If Statements

Syntax 

if (condition) {
    // Executed when condition is true
}
else if (anotherCondition) {
    // Executed when the first condition is false
    // and anotherCondition is true
}
else {
    // Executed when all preceding conditions are false
}

Initial Values 

let currentNumber = 0;
let targetNumber = 1;

[currentNumber] Initial number

[targetNumber] Target number

Example 1: If / Else If / Else 

if (currentNumber === targetNumber)
    "Target achieved";
else if (currentNumber > targetNumber)
    "Current number overshot target.";
else {
    currentNumber += 1;
    "Target missed, adding 1.";
}

[element-id-1] First conditional result

Example 2: Conditional With Multiple Statements 

if (currentNumber === targetNumber) {
    currentNumber += 1;
    "Target achieved. Stepping up once more.";
}
else if (currentNumber > targetNumber)
    "Current number overshot target.";
else
    "Under target number";

[element-id-2] Second conditional result

Example 3: Re-evaluating The Updated Value 

if (currentNumber === targetNumber)
    "Target achieved";
else if (currentNumber > targetNumber)
    "Current number overshot target.";
else
    "Under target number";

[element-id-3] Third conditional result

2. Ternary Operator

Syntax 

condition ? expressionIfTrue : expressionIfFalse;

Initial Values 

let someNumber = 1;
let someString = "1";

[someNumber] Some number

[someString] Some string

Strict Type Comparison 

let typeComparisonResult =
    (someNumber === someString)
        ? "Types are perfectly identical!"
        : "Data types do not match.";

[element-id-4] Ternary result

The strict equality operator (===) compares values without converting different data types into one another.

3. Switch Cases

Syntax 

switch (expression) {
    case value1:
        // Executed when expression matches value1
        break;

    case value2:
        // Executed when expression matches value2
        break;

    default:
        // Executed when no case matches
}

Initial Values 

let startingNumber = 0;
let endNumber = 5;
let addBuffer;

[startNumber] Starting number

[endNumber] End number

Example: Selecting A Value 

switch (endNumber) {
    case 1:
        addBuffer = 1;
        break;
    case 2:
        addBuffer = 2;
        break;
    case 3:
        addBuffer = 3;
        break;
    case 4:
        addBuffer = 4;
        break;
    case 5:
        addBuffer = 5;
        break;
    case 6:
        addBuffer = 6;
        break;
    default:
        addBuffer = 0;
}

[element-id-5] Selected value

Updating The Starting Number 

startingNumber += addBuffer;

[element-id-6] Resulting number

4. Logical Operators

Initial Values 

let bitA = 0;
let bitB = null;

[display-bitA] Bit A initial state

[display-bitB] Bit B initial state

Checking For Missing Values 

if (bitA === null || bitB === null || bitA === undefined || bitB === undefined) {
    bitA = bitA ?? 0;
    bitB = bitB ?? 0;
}

[bitNull] Missing-value check

[reAssigned] Reassignment status

[display-bitA-2] Bit A reassigned state

[display-bitB-2] Bit B reassigned state

Logical Gate Expressions

NAND 

let nandOutput = (bitA == 1 && bitB == 1) ? 0 : 1;

[display-nand] NAND output

NOT = NAND(bit, bit) 

let notOutput = (bitA == 1 && bitA == 1) ? 0 : 1;

[display-not] NOT output

AND = NOT(NAND(bitA, bitB)) 

let andOutput = (nandOutput == 1 && nandOutput == 1) ? 0 : 1;

[display-and] AND output

OR = NAND(NOT(bitA), NOT(bitB)) 

let orOutput =
    (
        ((bitA == 1 && bitA == 1) ? 0 : 1) == 1
        &&
        ((bitB == 1 && bitB == 1) ? 0 : 1) == 1
    )
    ? 0 : 1;

[display-or] OR output

XOR = NAND(NAND(NOT(bitA), bitB), NAND(bitA, NOT(bitB))) 

let xorOutput =
    (
        ((((bitA == 1 && bitA == 1) ? 0 : 1) == 1 && bitB == 1) ? 0 : 1) == 1
        &&
        ((bitA == 1 && ((bitB == 1 && bitB == 1) ? 0 : 1) == 1) ? 0 : 1) == 1
    )
    ? 0 : 1;

[display-xor] XOR output

5. Connecting JavaScript With HTML

Selecting An HTML Element 

document.getElementById("element-id-1");

getElementById() retrieves an element from the document using the element's id attribute.

Changing An Element's Content 

document.getElementById("element-id-1").innerHTML =
    "New content";

JavaScript can update the content of an existing HTML element without reloading the webpage.

Connecting An External JavaScript File 

<script src = "./script.js"></script>

The HTML document creates the elements, and the external JavaScript file contains the logic that selects and updates them.
