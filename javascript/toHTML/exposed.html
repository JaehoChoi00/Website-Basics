2. HTML Element IDs

3. Inline JavaScript Using onload

<body onload = "document.getElementById('element-id-2').innerHTML  =  '[element-id-2] Paragraph text changed using inline method';">

The second paragraph changes when the page finishes loading, because the JavaScript is attached to the body's onload event.

4. JavaScript Inside the HTML Document

<script>
    document.getElementById("element-id-1").innerHTML  =  "[element-id-1] Hello World!";
</script>

5. Linking an External JavaScript File

<script src = "/javascript/toHTML/script.js"></script>

Inside script.js: 

document.getElementById("element-id-3").innerHTML  =  "[element-id-3] Paragraph text changed from script.js file";
